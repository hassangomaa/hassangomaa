## What I do

I am a **backend-first software engineer** with **6 years** building production software — from REST and GraphQL APIs to real-time systems, authentication, and third-party integrations. I ship in **Laravel**, **NestJS**, and **FastAPI**, with a bias toward clean boundaries, explicit contracts, and code that survives production traffic.

Before software engineering, I trained in **network security** (Cisco CCNA track, CyberOps). That background shapes how I build: auth is not an afterthought, APIs are designed to be observable, and integrations are treated as failure-prone by default.

---

## AI & intelligent systems

I build backends that make AI **production-ready**, not demo-ready:

- **API-first AI services** — wrap models and automation behind REST/GraphQL with auth, rate limits, and observability
- **Document & data pipelines** — extraction, classification, and structured output from unstructured inputs
- **ML foundations** — Python work spanning SVM, ANN, and logistic regression ([academic project](https://github.com/hassangomaa/Selected_CS_1_Project_SVM_ANN_logistic_regression))
- **AI-augmented engineering** — ship faster with agent-assisted development while keeping tests, reviews, and security discipline non-negotiable
