## What I do

I am a backend-first software engineer with **6 years** building production software — from REST and GraphQL APIs to real-time systems, authentication, and third-party integrations. I ship in **Laravel**, **NestJS**, and **FastAPI**, with a bias toward clean boundaries, explicit contracts, and code that survives production traffic.

Before software engineering, I trained in **network security** (Cisco CCNA track, CyberOps). That background shapes how I build: auth is not an afterthought, APIs are designed to be observable, and integrations are treated as failure-prone by default.
